_Workstream 2. Make every number in the paper trace to generated simulation output, with a
build gate that fails on any hand-typed result number. Status: audit done; S0 will turn this
into a machine-checked manifest._

## Counts are provisional

The aggregate counts below (about 44 scripts emit a `.tex`, about 40 orphaned, about 27
consumed) were hand-assembled from greps after a shell orphan-check misfired. Treat them as
provisional. The named offenders each hold at their cited `path:line`. Chunk S0 re-derives all

## The intended pipeline

- `sims/sim_cache.py`: caching plus CLI flags. `compute_or_load(cache_dir, script, component,
  config, fn, ...)` caches per component; `add_component_args` adds `--data-only` /
  `--plots-only` / `--algo`.
- Each script's `generate_outputs(data)` writes both the PNG (`savefig`) and a `.tex` table via
  an f-string plus `open(path, 'w')`. No `pandas.to_latex`.
- `scripts/run_all_sims.py`: drives a hard-coded `REGISTRY` list (does not glob), writing
  `<script>_stdout.txt` per run.

Works for about 11 chapters, about 27 consumed tables.

## Target pipeline and gate (design)

- **S0 manifest:** one machine-readable file mapping every results number in the live build to
  a source class (generated-and-input / orphan-generated / hand-typed-table / prose-or-caption),
  each with a real `path:line`.
- **Gate (S5):** `scripts/check_numbers.py` scans the live chapter tex, and fails the build if a
  results number is not traceable to a generated `.tex` or a `*_macros.tex` macro. Wire into the
  build so "ruthless" is durable, not a one-time pass.
- **Staging:** tables first (S1, S2), then captions and prose via macros (S3), then the gate (S5),
  then a full rebuild with a hash check that every consumed number matches fresh output (S6).
